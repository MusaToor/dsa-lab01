## Task Descriptions

Task 1: Create an array with 2, 4, 6, 8, 10, change third element to 7, display all values using a for loop.

Task 2: Read five integers into an array and calculate their sum using two loops, display the total.

Task 3: Define a Student class with rollNumber and marks, create two objects s1 and s2, assign values, display them, then change s1.marks to 80 and display again.

Task 4: Read 8 integers into an array, find and display the largest and smallest values with their indices.

Task 6: Read 6 integers into an array, reverse the array without using another array, display the result.

Task 7: Read 10 integers into an array, move first occurrence of each distinct value to the beginning without using another array, display unique values and count.

## Task 3 Test Results

Initial assignment:
s1 (rollNumber=1, marks=75)
s2 (rollNumber=2, marks=90)

After changing s1.marks to 80:
s1 (rollNumber=1, marks=80)
s2 (rollNumber=2, marks=90) - unchanged

Observation: When s1.marks is changed to 80, s2.marks remains 90. This shows that each object has its own independent copy of data members. Changing one object does not affect the other object.
